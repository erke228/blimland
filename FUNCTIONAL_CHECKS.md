# Проверка реализованных функций

Дата: 19 октября 2026 года. Проверяются текущие функции, а не весь первоначальный каталог будущих возможностей.

## Результат

- `npm run typecheck` — успешно.
- `npm run build` — успешно.
- `npm test` — 36 проверок, все успешно.
- `npm run test:integration` — сквозной HTTP-сценарий успешно.
- Браузер — отдельные представления студента и главного администратора; профиль, dashboard, настройки и мобильная форма группы проверены.

## Дополнительные проверки сервисов

- Только один главный администратор, включая прямую SQL-вставку.
- Запрет блокировки и понижения роли владельца.
- Проверка ролей и владельца на сервере.
- Соль паролей, хеши токенов сессий и приглашений, срок сессии.
- Ограничение запросов, откат незавершённой транзакции.
- Срок и лимит приглашения, повторное подтверждение без расхода лимита, отказ учителю по студенческому приглашению.
- Сохранение индивидуального обучения при удалении участника преподавателем.
- Минимальные DTO участников, запрет доступа постороннему преподавателю/студенту, скрытие заблокированных, отзыв доступа после исключения.
- Запрет назначения чужого курса преподавателем и обхода оплаты.
- Границы учебного года, допустимых URL и локального перехода после входа.
- Поиск по казахским буквам без зависимости от регистра ввода.
- Согласованность заявки при ручном снятии преподавательской роли.
- Некорректный PDF/DOCX, старый .doc, превышение 20 МБ, недопустимый путь, чужая загрузка, архив курса и подмена типа файла.
- HTML Word: удаление скриптов, активных атрибутов, SVG, внешних изображений и стилей; проверка структуры ZIP и запрет макросов.

## Проверка внешнего вида

- Noto Sans загружается локально; внешний Google Fonts импорт удалён.
- `document.fonts.check` подтвердил загрузку для «Әә Ғғ Ққ Ңң Өө Ұұ Үү Һһ Іі».
- Профиль студента: единственный неброский свёрнутый пункт заявки внизу, без карточек-рекламы.
- Казахские подписи и отдельная навигация главного администратора проверены в браузере.
- Экран 390×844: настройки и форма новой группы; горизонтального выхода всей страницы за экран нет. Навигационные вкладки прокручиваются внутри своей области.
- Первая настоящая лекция: PDF 16 страниц, переходы 1/2/16, масштаб 100/125%, изображения и казахский текст. Встроенный Word проверен в отдельной тестовой базе с казахским текстом и таблицей.
- PDF на экране 390×844: ширина страницы 375 CSS px при viewport 390, canvas 285 px; горизонтального выхода всей страницы нет. Номер страницы и масштаб работают. Временный размер экрана после проверки сброшен.

## Что не является готовым и проверенным

- Полный конструктор тестов, банк вопросов, викторины, оценивание знаний и журнал тестовых баллов ещё не реализованы.
- Загрузка PDF/DOCX работает. Загрузка видео, объектное хранилище, транскодирование, субтитры и сохранение позиции ещё не подключены. Видео пока по прямой HTTPS-ссылке; приёмка реальной учебной видеотеки не проводилась.
- Почта, восстановление пароля, платежи и выплаты преподавателям не подключены.
- PostgreSQL, объектное хранилище, публичный сервер, резервирование и нагрузка большого университета требуют следующих этапов.
- Казахская редактура носителем языка ещё не выполнена.

Тестовые HTTP-сценарии используют отдельные SQLite-базы в `.test-data/`. Рабочие пользовательские записи не очищались, реальные заявки не одобрялись автоматически ради проверки.
