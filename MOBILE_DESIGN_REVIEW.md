# Мобильный интерфейс студента

Проверено 28 октября 2026 года. Приоритет — обучение с телефона. Интерфейс остаётся казахским, локальный Noto Sans сохраняется.

## Что показал разбор

| Проблема | Изменение |
| --- | --- |
| Основные переходы спрятаны в боковом меню | Постоянные четыре пункта снизу: главная, каталог, моё обучение, профиль |
| Подписи 8–11 px, мелкие поля и кнопки | Основной текст 14–16 px, поля 16 px, основные действия от 44 px |
| Фильтры занимают первый экран каталога | Поиск открыт сразу, остальные фильтры раскрываются отдельно; выбранные параметры отмечены счётчиком |
| Кнопка доступа к курсу находится после всей программы | На телефоне доступ/продолжение стоит перед программой, обложка компактная |
| Кабинет требует повторно искать текущий урок | Карточка продолжения открывает первую непрочитанную лекцию доступного курса; после завершения — повторение |
| Боковой список и обложка мешают читать лекцию | Программа раскрывается над содержимым; декоративная обложка скрыта только на телефоне |
| PDF имеет маленькие элементы управления | Кнопки 44 px, панель закрепляется под шапкой; увеличение прокручивается внутри документа |
| Профиль перегружен длинной группой и формами | Компактная раскрываемая группа перед формой, три вкладки, крупные поля, выход рядом с именем |

Главная сохраняет иллюстрации и реальные карточки; мобильная композиция отдельная. Длинное описание курса можно раскрыть, короткое не обрезается. Текст лекции — 16 px с увеличенным интервалом. Word имеет ограниченную высоту встроенного просмотра. Нижняя панель и шапка учитывают безопасные зоны экрана; увеличивать страницу пользователю разрешено. Добавлены ссылка перехода к содержимому, подписи кнопок, состояния раскрытия и видимый клавиатурный фокус. Навигация преподавателя и администратора использует их собственный кабинет.

## Проверка

Браузерный профиль студента создан только в отдельной `.test-data/mobile-redesign.sqlite`; PDF, Word, три урока и группа — изолированные проверочные данные. Рабочие аккаунты, пароли, прогресс и материалы не изменялись. Сессии разделены по localhost/127.0.0.1.

- 320×844 и 430×844: главная, каталог, кабинет, профиль, PDF, Word, текстовая лекция. Ширина документа 305/415 px при viewport 320/430; переполнения всей страницы нет.
- 390×844: применение PDF-фильтра, его счётчик и сворачивание; кабинет; группа и краткий профиль участника; редактирование; чтение. Страница курса и PDF дополнительно проверены при 320×740.
- 768×1024, 844×390 и 1280×900: каталог, курс, PDF и профиль. Переполнения страницы нет; на компьютере боковая навигация и полные списки сохраняются.
- PDF: переключение 1→2, увеличение 100→125%, внутреннее горизонтальное перемещение при неизменной ширине страницы. Вертикальная прокрутка может продолжиться за пределы документа. Кнопки измерены: 44 px.
- Word: безопасное HTML-представление показывает казахские буквы, ссылку и таблицу; высота встроенного просмотра адаптирована к экрану.
- Отметка о прочтении сохранилась в SQLite. Кабинет после неё показывает 33% и ссылку на второй, непрочитанный урок. Данные сохраняются после выхода и повторного входа.
- Форма контактов: сохранение города подтверждено ответом сервера и чтением тестовой БД. Поля профиля/безопасности и регистрации — 16 px; поля профиля — 52 px по высоте. Пароли не менялись.
- Выход, вход, внешний вид регистрации; закрытые профили и данные одногруппников не раскрываются. Создание новых реальных пользователей ради проверки не выполнялось.
- `document.fonts.check` подтвердил локальный шрифт для Әә Ғғ Ққ Ңң Өө Ұұ Үү Һһ Іі. В журнале браузера ошибок нет.
- `npm test`: 62/62. `npm run test:integration`, `npm run build`, `npm run typecheck`: успешно. Серверные проверки прав и доступа к документам сохранены.

Это проверка размеров экрана в браузере Chromium. Реальные Safari/iOS, Android-клавиатура, системный просмотр файлов и аппаратные безопасные зоны требуют отдельной проверки на устройствах; их поведение не выдаётся за проверенное.

## Локальные доказательства

Снимки и измерения находятся в игнорируемой `.local/qa/`:

- `mobile-dashboard-before.png`, `mobile-catalog-before.png` — до изменений.
- `mobile-home-after.png`, `mobile-catalog-after.png`, `mobile-dashboard-after.png`, `mobile-profile-after.png`, `mobile-reader-after.png` — после изменений.
- `mobile-viewport-checks.json` — размеры страниц и состояние навигации.

Тестовые пользователи и уроки на рабочем сайте не появляются. Следующий учебный этап остаётся M03: составные блоки лекции, далее видео и тесты; мобильная переработка не означает готовность этих функций.
