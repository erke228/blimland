# BilimHub

Самостоятельная образовательная платформа для Казахстана. Интерфейс — казахский; документация — русский. Рабочее название не утверждено как бренд.

## Как продолжать разработку

Сначала прочитать `AGENTS.md`, `AI_EXECUTION_PLAN.md` и `PROJECT_STATE.md`. Полные продуктовые требования — в `PROJECT_PLAN.md`.

## Локальный запуск

Подключение Neon/Vercel, перенос данных и границы проверки описаны в `NEON_DEPLOYMENT.md`. Если `.env.local` содержит переменные Neon, Next.js использует эту базу. Для изолированной локальной работы сначала явно задайте `DATABASE_DRIVER=sqlite`, `STORAGE_DRIVER=local` и отдельные пути `DATABASE_PATH`/`UPLOAD_DIR`; не используйте production для экспериментов. PostgreSQL-схема применяется отдельно через `npm run db:migrate:postgres`, импорт рабочей SQLite — только в пустую базу. Обычные SQLite-команды ниже не заменяют PostgreSQL-миграцию.

Нужен Node.js 22.13+; для следующего производственного этапа рекомендуется актуальный поддерживаемый LTS. В установленном Node 22 встроенная SQLite выдаёт предупреждение об экспериментальном API.

```powershell
npm ci
npm run db:migrate
npm run db:seed
npm run dev
```

Открыть http://127.0.0.1:3000. Настройки по умолчанию работают без `.env`. При необходимости скопировать `.env.example` в `.env.local`. CLI-команды читают настройки из переменных окружения оболочки; Next.js также читает `.env.local`. Для одинакового пути БД у CLI и приложения задавать `DATABASE_PATH` в оболочке.

`db:seed` больше не создаёт демонстрационные курсы и пользователей. Команда применяет миграции и архивирует три известных старых примера, сохраняя их историю. В каталоге остаются реальные опубликованные материалы. Команда не запускается автоматически; пользовательские записи не очищаются.

## Администратор

```powershell
npm run admin:create -- owner@example.kz "Платформа әкімшісі"
```

Команда создаёт нового администратора и один раз выводит случайный начальный пароль. Сохранить его безопасно. Существующая запись не повышается в правах и её пароль не перезаписывается. Не публиковать вывод команды.

Главный администратор только один; это проверяется также ограничением базы. Он управляет всеми пользователями, курсами, группами, журналом и настройками в `/admin`.

Для локальной проверки без собственного аккаунта владельца можно явно выполнить `npm run preview:setup`. Команда создаст единственного локального владельца только при его отсутствии. Случайный пароль сохранится в игнорируемом `.local/preview-access.txt`; аккаунты и пароли уже существующих пользователей не меняются. На публичном сервере эту проверочную команду не запускать.

## Проверка учебного сценария

1. Зарегистрировать ученика и записаться на курс.
2. Открыть урок и отметить его прочитанным; проверить кабинет и повторный вход.
3. Зарегистрировать отдельного пользователя, открыть `/profile` и раскрыть неброский пункт заявки внизу страницы. Регистрация создаёт только студента и сама заявку не отправляет.
4. Администратором одобрить заявку на `/admin`.
5. Учителем создать курс, раздел и урок с текстом и, при наличии, прямой HTTPS-ссылкой на видеофайл.
6. Отправить курс на проверку. Администратором просмотреть и опубликовать.
7. Учеником записаться и открыть закрытый урок.

По запросу 28.10.2026 платёжная система полностью удалена: цен, продаж и платного доступа нет. Запись на опубликованные курсы и назначение курсов группам работают без оплаты. Миграция `008_remove_course_pricing` удаляет столбец цены, сохраняя учебные данные.

## Учебные группы и управление

Преподаватель создаёт группы в `/teacher/groups`, указывает кафедру, учебный год и семестр. Опубликованные курсы можно назначить группе: существующие и присоединяющиеся студенты будут записаны на них.

Приглашение имеет срок 1/7/30 дней, лимит вступлений и возможность отзыва. Новая ссылка показывается сразу после создания в течение 10 минут. В самой базе хранится только хеш токена. Студент открывает `/join/<token>`, входит или регистрируется и отдельно подтверждает вступление. Состав группы и отчёты видят только её преподаватель и главный администратор.

Студент видит свои группы только в `/profile`, без кнопок управления. Карточки одногруппников ведут на краткий профиль с именем и ролью; доступ проверяется по общему членству на сервере. Email, активность и результаты одногруппникам не передаются. Старый `/groups` перенаправляет в профиль.

Отчёт преподавателя показывает прочитанные уроки по каждому студенту и курсу, есть CSV. Это ручной прогресс чтения, а не оценка знаний. Приглашениями и составом управляет преподаватель либо главный администратор. Архив группы и удаление участника не удаляют историю и индивидуальную запись на курс.

Администратор редактирует профили и роли, блокирует пользователей с отзывом сессий, модерирует и архивирует курсы, меняет название сайта/университета, объявление и открытость регистрации. Профили самих пользователей доступны для редактирования в `/profile`. Заявки преподавателей приходят на главный dashboard.

Главная `/` с иллюстрацией и карточками открывается для всех ролей через «Басты бет». Кабинеты администратора, преподавателя и студента доступны отдельными пунктами; после входа сохраняется переход в соответствующий кабинет.

Для текущей локальной установки по прямому запросу владельца настроен пароль демо-преподавателя. Данные находятся только в игнорируемой `.local/teacher-preview-access.txt`; данные главного администратора — в `.local/preview-access.txt`. Не включать эти файлы в Git или публичное размещение. Обычная команда seed не выдаёт преподавательского пароля новой установки.

Интерфейс использует локальный Noto Sans, включая казахскую расширенную кириллицу. Подключение к Google Fonts для отображения шрифта не требуется.

Разбор структуры и предлагаемых дополнений: `UNIVERSITY_DESIGN_REVIEW.md`. Фактические проверки и ограничения: `FUNCTIONAL_CHECKS.md`.

Обычная ссылка на страницу YouTube не является прямым видеофайлом. Загрузка файлов, приватное видеохранилище, транскодирование и сохранение позиции ещё не подключены. Внешний URL видео может быть доступен вне платформы.

## Команды проверок

```powershell
npm run typecheck
npm test
npm run build
npm run test:integration
```

Интеграционная проверка требует готовой сборки, поднимает отдельный локальный сервер на свободном порту, создаёт отдельную БД в игнорируемой `.test-data/` и завершает свой сервер. Рабочая база не очищается.

## Сборка и запуск

```powershell
npm run build
npm start
```

Пока это локальный рабочий контур. Публичное размещение, HTTPS, подтверждение email, восстановление пароля, мониторинг, нагрузочная проверка, производственное хранилище вынесены в последующие этапы. Публичный запуск выполнять после подготовки серверного окружения.

Для HTTPS установить `COOKIE_SECURE=true`. В режиме разработки применяется обычная cookie для локального HTTP. База и загруженные файлы исключены из Git; резервирование на сервере должно охватывать их отдельно от кода.

## Архитектура

Подробный редактор курса, разделов и лекций, загрузка обложек и выбор восьми иллюстраций: `COURSE_EDITOR.md`. Обложка JPG/PNG/WebP хранится вне Git/public; лимит 5 МБ, серверное преобразование в WebP и проверка доступа. У лекций возможна собственная обложка или наследование из курса. Миграции `004_course_editor` и `005_lecture_covers` должны быть применены перед запуском обновлённого приложения.

Первую лекцию Тлеужановой Қ. Е. можно открыть в `/learn/byte-pair-encoding`. PDF/DOCX можно выбрать сразу при создании лекции или добавить в блоке документов над редактором сохранённого урока-черновика: 20 МБ на файл. PDF читается постранично, Word — как безопасный документ внутри урока. Миграция `006_section_trash` добавляет удаление/восстановление разделов с сохранением лекций и истории. Детали: `DOCUMENT_VIEWER.md` и `COURSE_EDITOR.md`.

`UPLOAD_DIR` должен указывать на постоянную папку вне `public`. Она содержит оригиналы и представления Word; резервируйте её вместе с SQLite. `npm run dev` и `npm run build` готовят локальные библиотеки просмотрщика автоматически. При запуске используйте тот же origin, который указан в `APP_ORIGIN`, иначе проверка отправки формы отклонит загрузку.

- `src/app` — страницы и серверные действия Next.js.
- `src/components` — интерфейс и плеер.
- `src/lib` — БД, авторизация, безопасность и чтение курсов.
- `db/migrations` — неизменяемые применённые SQL-миграции.
- `scripts` — миграции, архив прежних примеров, импорт лекции, создание администратора, сквозная проверка.
- `tests` — автоматические проверки безопасности и хранения.

SQLite рассчитана здесь на один локальный процесс/экземпляр. Для целевой большой платформы до публичного запуска запланированы PostgreSQL и объектное хранилище. Зависимости зафиксированы lock-файлом.
