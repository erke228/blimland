# Автономное улучшение платформы и исследование ИИ

Запрос владельца 04.11.2026: повторный Vercel deployment, проверка Neon, исследование бесплатного/локального ИИ. Не покупать серверы, кредиты или подписки. Не отправлять реальные профили, ответы студентов и ключи тестов внешним моделям. Не добавлять неработающую кнопку ИИ в продукт.

## Вывод по размещению

Проверенные бесплатные Gemini/Groq API имеют ограничения запросов и токенов; обещать безлимит нельзя. Отдельный постоянный сервер с Ollama позволяет работать без тарификации каждого токена, но ограничен RAM, скоростью, длиной контекста и расходами на сервер/электричество. Docker — способ запуска, сам по себе бесплатный сервер не предоставляет.

На компьютере обнаружены примерно 16 ГБ RAM, Intel UHD и RTX 4060 Laptop GPU; размер VRAM через Win32_VideoController ненадёжен, отдельно не подтверждён. Docker/Ollama в PATH отсутствуют. Установка Docker с виртуализацией и возможной перезагрузкой без владельца не выполнялась. Ни одна модель не считается запущенной или проверенной по качеству.

PostgreSQL/Neon оставить для учебных данных, поиска и при необходимости векторов pgvector; не помещать веса модели в рабочие таблицы и не считать pgvector генератором ответов. Модель запускается отдельным процессом/контейнером. Vercel не сможет обращаться к localhost компьютера владельца. Для постоянной работы нужен отдельный доступный сервер либо ограниченный облачный API. Внешний сервер должен иметь HTTPS, аутентификацию и ограничения запросов; сырой Ollama-порт в интернет не публиковать.

## Подготовленный локальный стенд

`infra/ai/compose.yaml`: официальный Ollama image закреплён digest из Docker Hub на 04.11.2026; порт только loopback, облачные функции выключены, 4 ГБ RAM, 1 параллельный запрос. GPU не объявляется подключённым; начальный стенд CPU.

После установки Docker на выбранном компьютере/сервере:

```text
docker compose -f infra/ai/compose.yaml up -d
docker compose -f infra/ai/compose.yaml exec ollama ollama pull qwen3:1.7b
node scripts/check-local-ai.mjs
docker compose -f infra/ai/compose.yaml stop
```

Qwen3:1.7b — начальный кандидат около 1.4 ГБ по карточке Ollama, не обещание хорошего казахского языка. Стенд не использует production env/БД. Скрипт проверяет доступность, установленную модель и один синтетический казахский пример 0.1 кВт·сағат; при отсутствии сервиса завершает работу с кодом 2, не имитирует успешный ответ. Контейнер, загрузка весов и inference в этой среде не выполнены из-за отсутствующего Docker.
