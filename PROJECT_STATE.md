## Что работает

- Казахский интерфейс университета с локальным Noto Sans и расширенной кириллицей.
- Регистрация всегда создаёт студента. В регистрации нет преподавательской заявки.
- Один свёрнутый неброский пункт внизу `/profile`: подача заявки, статус и комментарий возврата. После одобрения появляется рабочий кабинет учителя.
- Отдельный `/admin`: сводка, пользователи, все курсы, группы, журнал и настройки.
- Главный администратор редактирует профиль, email, роль и статус пользователя; блокировка или смена чувствительных полей отзывает сессии. Владельца нельзя случайно заблокировать/понизить; второй admin запрещён уникальным индексом БД.
- Преподаватель ведёт свои группы; главный администратор — все. У группы есть кафедра, учебный год, семестр и описание.
- Назначение опубликованных бесплатных курсов; платный доступ приглашением не обходится.
- Приглашения с хешем токена, сроком, лимитом, отзывом и отдельным подтверждением студентом. Повторное принятие идемпотентно.
- Отчёт по студенту/курсу и CSV только преподавателю группы и главному администратору.
- Свои группы студента размещены в `/profile`; отдельный пункт групп и приглашения к управлению убраны. `/groups` перенаправляет по роли.
- Краткие профили `/profile/people/[id]` содержат только имя и роль. Сервер допускает одногруппников и их преподавателя; чужой или заблокированный профиль — 404. Email, личные поля, активность и прогресс одногруппникам не передаются.
- Состав и приглашения меняют только преподаватель группы или главный администратор. Архив и удаление участника не удаляют индивидуальную запись и учебную историю.
- Редактирование собственного имени, кафедры и академического статуса в профиле.
- Редактор курсов, разделов и лекций: сведения курса, краткое описание и цели лекции, порядок и перенос между разделами, документ после сохранения без повторного поиска лекции. Лекция наследует обложку курса либо получает отдельное изображение/иллюстрацию; можно вернуть наследование. У черновика файл доступен только автору/главному администратору. Проверка Origin, роли, владельца и размеров на сервере.

## Технические ограничения

- SQLite — локальный первый контур. Большой публичный университетский запуск, PostgreSQL, объектное хранилище и нагрузка ещё не подготовлены.
- В установленном Node 22 API SQLite выдаёт предупреждение об экспериментальном статусе.
- Просмотренный/прочитанный урок не является доказательством освоения темы. Тестовых оценок пока нет.
- Видео сейчас только по прямой внешней HTTPS-ссылке. Такой URL не защищает платный файл.
- `.docx` представлен для чтения; сложные формулы, стили и пагинация могут отличаться. Для точной страницы требуется PDF. Зашифрованные PDF, старые .doc и макросы не поддержаны.
- `npm audit` сообщает 3 moderate в цепочке CLI-зависимости Mammoth → argparse → sprintf-js. Приложение не использует этот CLI; конвертация выполняется в отдельном worker с лимитом памяти/времени. До публичного запуска пересмотреть зависимость и полный аудит.
- Опубликованные материалы редактируются после возврата в черновик; безопасные версии без остановки опубликованного курса впереди.
- В составном уроке пока только один текст и одна видеоссылка. Полный набор блоков обязателен в M03.
- Ручное создание пользователей через веб, безопасный сброс пароля, передача владения, помощники преподавателей и университетская авторизация остаются в плане; не добавлять имитации.
- Привязанный к группе курс при её архиве или удалении участника остаётся в индивидуальной записи — это намеренное правило сохранения истории.
- Бренд, реальное название университета, бюджет и сервер владельцем пока не выбраны. Это не мешает M03–M09.
