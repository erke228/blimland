## Принятые технические решения

- Самостоятельное приложение, поскольку требуется открытая регистрация без обязательного аккаунта ChatGPT.
- Next.js + TypeScript; локальная SQLite для первого рабочего контура.
- Казахский интерфейс; рабочее название BilimHub, оно не утверждено как бренд.
- Внешние платежи, почта, видеотранскодирование и публичный хостинг пока не подключены.

## Реализовано в первом рабочем проходе

- Next.js 16.4.2, React 19.3.1, TypeScript, зафиксированные зависимости.
- База SQLite с отдельной миграцией; пользовательские данные исключены из Git.
- Команда явного создания трёх демонстрационных курсов без общедоступного пароля.
- Казахские каталог, фильтры, поиск с учётом казахских букв и регистра ввода.
- Регистрация, вход, выход, хеширование паролей scrypt, отзываемые сессии с хранением только хеша токена.
- Начальная роль всегда «ученик»; преподаватель получает права через решение администратора.
- CLI создания администратора со случайным паролем; публичного назначения администраторов нет.
- Кабинеты ученика, преподавателя и администратора.
- Создание курса и разделов, добавление/редактирование текстового урока с прямой HTTPS-видеоссылкой.
- Предпросмотр автором и администратором, проверка перед публикацией.
- Бесплатная запись, ограничение доступа к закрытым урокам, ручной прогресс.
- Платная запись не имитируется: сервер не выдаёт доступ к платному курсу по бесплатному действию.
- Базовый журнал одобрений и публикаций, ограничения частоты входа и регистрации.

## Ограничения текущей версии

- Это локальный первый рабочий контур, не готовый публичный коммерческий сервис.
- Конструктора тестов, настоящих загрузок, видеообработки, почты и оплаты ещё нет.
- Прямая внешняя видеоссылка не обеспечивает приватность файла; защищённое платное видео требует M04/M10.
- Опубликованный курс в этой версии закрыт для редактирования; история версий и безопасное обновление впереди.
- Блоки урока пока представлены одним текстом и одной видеоссылкой; целевой многоблочный редактор ещё требуется.
- Ручной процент прочтения не является подтверждением освоения материала.
- Данные профиля пока доступны только для чтения; уведомлений и восстановления пароля нет.
- SQLite локальная, синхронная; производственный масштаб, почтовая проверка адресов, полноценная доступность и нагрузка пока не проверялись.
- Встроенная SQLite в установленном Node 22 выдаёт предупреждение об экспериментальном API.
- Бренд, платёжная модель, провайдеры и сервер владельцем пока не выбраны. Эти вопросы не мешают M03–M09.
