# Подготовка домена bilimhub.eu.org

Состояние на 29 октября 2026 года: DNS на Vercel подготовлен; владелец отправил заявку EU.org, она ожидает одобрения. Оплата регистрации, покупка домена, перенос регистрации и изменение тарифов не выполнялись.

## Заявка EU.org

Номер: `20261028215223-arf-64356`. Владелец предоставил вывод EU.org: `No error, storing for validation... Saved as request 20261028215223-arf-64356 / Done`.

Проверка EU.org получила одинаковый SOA serial `1793219856` и успешные NS-ответы от обоих серверов Vercel по IPv4 и IPv6. Техническая проверка пройдена, заявка сохранена на рассмотрение. Отправку выполнил владелец вручную; автоматизация Brave останавливалась из-за невозможности подтвердить URL.

После получения результата повторно проверены публичный DNS и Vercel: `ENOTFOUND`, `misconfigured: true`, назначенные NS ещё не делегированы. Это ожидающая рассмотрения заявка, а не активный домен. Повторно отправлять её не нужно. Следующий шаг — после одобрения выполнить проверки ниже; фоновое наблюдение не создано.

## Что уже сделано

- Домен `bilimhub.eu.org` добавлен в Vercel `vitsa/bilimhub`, проект `prj_RA61V3rNdFVuUs9gojOo6csaSZq1`.
- Включена DNS-зона Vercel. Значения взяты из `intendedNameservers`, а не из примера документации.
- Оба сервера напрямую возвращают SOA, NS и A для новой зоны. ALIAS и CAA управляются Vercel автоматически.
- Действующий адрес https://bilimhub-vitsa.vercel.app отвечает HTTP 200.
- Публичное NS-делегирование ещё отсутствует (`ENOTFOUND`). Это не доказывает доступность регистрации имени.

## Данные для заявки EU.org

Полное имя домена:

```text
bilimhub.eu.org
```

DNS-серверы — каждый в отдельной строке/поле:

```text
ns1.vercel-dns.com
ns2.vercel-dns.com
```

Для этих серверов не нужен собственный glue: они находятся вне запрашиваемого домена. Если форма не требует IP, поля IP оставить пустыми; не копировать A-адрес сайта в поля адресов DNS-серверов.

Ранее подготовленное описание проекта на английском (включение именно этого текста в отправленную заявку не проверялось):

```text
BilimHub is a free Kazakh-language educational platform for university lecturers and students in Kazakhstan. Lecturers publish lecture materials, organize student groups and track learning progress. The platform has no payments or course sales. The current website is https://bilimhub-vitsa.vercel.app. We request bilimhub.eu.org as the public address of this educational project.
```

Контакты — существующий подтверждённый аккаунт владельца EU.org. Не создавать вымышленные контакты, не сохранять адрес, телефон, пароль или cookie аккаунта в Git. Владелец самостоятельно подтверждает почту и проходит вход/CAPTCHA при необходимости.

EU.org требует заранее настроенные DNS-серверы и ручное рассмотрение заявки: https://nic.eu.org/register.html. Прямые имена внутри EU.org рассматриваются по отдельной политике: https://nic.eu.org/top-policy.html. Отправка не означает одобрение; срок не гарантирован.

## Что проверить после одобрения

1. Публичный DNS возвращает оба назначенных NS для `bilimhub.eu.org` и A/AAAA сайта.
2. Vercel перестаёт помечать конфигурацию как `misconfigured`; выпущен действительный HTTPS-сертификат.
3. По https://bilimhub.eu.org открываются главная, каталог и реальная лекция/PDF.
4. Вход/выход и серверные ограничения ролей работают на новом домене. Существующие сессии старого адреса автоматически между разными доменами не переносятся.
5. Пока новый адрес полностью не проверен, действующий адрес Vercel сохраняется.

## Граница текущей проверки

`verified: true` в Vercel означает добавление домена к аккаунту/проекту; это не регистрация в EU.org. DNS-зона на Vercel готова, но публичный запуск по новому имени пока не завершён. Не повторять импорт базы, не менять пользователей или пароли ради подключения домена.
